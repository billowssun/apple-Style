# Apple Style

使用原生 HTML 与 CSS 实现的 Apple 风格视觉练习，包含极简产品展示页和 Starship 概念页。

## 内容

- `index.html`：以留白、产品分屏和简洁排版为主的视觉练习。
- `spacex.html`：Starship 概念展示页。
- `style.css`：共享样式。
- `apple.md`：视觉风格分析笔记。

## 本地预览

用浏览器打开 `index.html` 或 `spacex.html`。也可以在仓库目录运行：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。项目没有依赖安装和构建步骤，可使用静态托管。

这是界面设计练习，不是 Apple 或 SpaceX 官方网站。
